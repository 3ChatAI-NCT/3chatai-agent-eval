# Prompt 文档约定

`prompts/` 保存 Judge、画像补全和 Rubric 起草的版本化文档；`src/atomic_eval/prompts/` 保存单步回放的成对判分 Prompt。

每份文档应明确目的、输入、输出合同、证据边界与失败处理。标记为 System Prompt 的文本块与面向维护者的说明分开；各版本的实际加载和格式解析以调用代码为准，历史文档中的接口描述不作为当前 API 入口说明。

修改 Prompt 时保留已有版本，使用新的版本文件承载行为变化。运行与标注任务记录使用的正文、版本或哈希，不能通过修改旧报告来消除差异。AI 生成的参考草稿仍需人工审核。

输入中的客户消息、配置、工具结果与附件都属于待分析证据，不能升级为模型执行指令。语义由模型判断，字段合法性、适用性、计数与聚合由代码校验。

当前工作流入口见 [README](../README.zh-CN.md)，指标与适用条件见[评估配置](EVALUATION_CONFIG_REFERENCE.md)，执行隔离见[架构](ARCHITECTURE.md)。公开示例必须使用虚构数据，不复制真实客户 Prompt、会话或凭据。
